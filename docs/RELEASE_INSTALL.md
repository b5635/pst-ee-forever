## Install

**Needs:** _Planescape: Torment: Enhanced Edition_, **GOG 3.2.2.0** (64-bit), on Windows. Other `Torment.exe`
builds are not supported. Back up your saves first, especially before using the 8-member party.

1. Download `pst_forever-<version>.zip` below (not "Source code").
2. Unzip it into the game folder, next to `Torment.exe`
   (for example `C:\GOG Games\Planescape Torment - Enhanced Edition`). Let it merge the `override` folder.
3. Start the game as usual.

**Options:** run `pst_forever_config.exe` in the game folder.

**Dynamic lighting (optional):** also download
[`pst_forever-v0.1.1-lighting.zip`](https://github.com/b5635/pst-ee-forever/releases/download/v0.1.1/pst_forever-v0.1.1-lighting.zip)
(690 MB, about 1.4 GB unpacked), unzip it into the same game folder, and switch lighting on in the options window. You
only need to download it once; updating the mod keeps it.

**Update:** the zip replaces `pst_forever\pst_forever.ini` with the defaults. If you changed settings, copy that
file somewhere else first, then set them again in the options window.

**Uninstall:** delete `version.dll`, `pst_forever.dll`, `pst_forever_config.exe`, the `pst_forever` folder, and
`override\PF*.*`, `override\PORTRT6.BMP` and `override\PORTRT7.BMP` from the game folder.

**Problems:** attach `pst_forever\logs\pst_forever.log` to an
[issue](https://github.com/b5635/pst-ee-forever/issues), or ask on [Discord](https://discord.gg/AgRUs6wwVM).
