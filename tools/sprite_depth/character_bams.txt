# Character sprite BAMs of PST:EE 3.2.2 (creature animations only), written by
# `python -I tools/sprite_depth/sprite_depth.py list`.
# How: EE maps a creature's ANIMATE.IDS value 0xF000+n to section [n] of RESDATA.INI
# (resource type 0x802 in chitin.key). Every sequence key there (attack*, walk, run, stand*,
# stance*, diebackward, getup, gethit, spell*, talk*, misc*) names a 7-char base; the file is
# base + 'B' (the GemRB avatars.2da prefixes are the same CxxxB/DxxxB names). Where the C/D letter
# in RESDATA is wrong (Baurier: CAT1BAU -> DAT1BAUB) the other letter is used. Plus the static
# creatures without a section: Iron Golem (IGHEAD, IGARM, IGARMB) and Pillar of Skulls (POSMAIN).
# Left out: spell effects, projectiles, area animations, GUI, the Foundry gears, shadow/effect
# overlays (POSSHAD, POSTANT, IGSPARK) and 77 classic-only C*B leftovers no RESDATA entry loads
# (e.g. CWLKNOFB; EE draws the D* versions).
